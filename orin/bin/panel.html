Record & map

Records the cloud and the IMU while you walk; on stop, FAST-LIO2 replays it into a map (takes as long as the walk). Walk a loop that returns to the start: the gap between start and end shows the drift. Roughly 0.3 GB per minute. Can run alongside Live.

Live SLAM

Maps and localises as the robot walks; the map, the path and the robot's position refresh every 0.2 s. Start with the robot standing still (the first second levels the map by gravity). Stop saves the map to the library and to Navigate's floor maps.
